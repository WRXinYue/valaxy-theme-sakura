# Archives 归档 (Timeline)

Valaxy Theme Sakura 提供了全新的归档页面（时间轴）体验，包含丰富的动画效果和交互功能。

## 新特性

### 1. 节点设计
- **年份节点**：作为一级导航，双击可展开/收起该年份下的所有月份。
- **月份节点**：采用大圆圈样式，清晰区分不同月份。
- **文章节点**：采用小圆圈样式，通过垂直线条连接，形成连贯的时间轴。

### 2. 交互逻辑

#### 悬停预览 (Hover)
默认情况下，月份下的文章列表是收起的。当你将鼠标悬停在月份节点上时，文章列表会展开预览。移出鼠标后，列表会在短暂延迟（300ms）后自动收起，防止误触。

#### 点击锁定 (Click Lock)
如果你想固定查看某个月份的文章，可以**点击**月份节点。
- **锁定状态**：节点会被激活（显示激活样式），文章列表保持展开，即使移开鼠标也不会收起。
- **解锁**：再次点击已锁定的节点，即可取消锁定并收起列表。

#### 年份批量操作
- **双击年份**：
  - 如果该年份下有未展开的月份，双击将**全部展开并锁定**。
  - 如果该年份下所有月份都已展开，双击将**全部收起**。
- **激活状态**：当某年份下的所有月份都处于展开状态时，年份标题和节点会高亮显示（变为主题色）。

### 3. 动画效果
- **垂直伸缩**：展开和收起文章列表时，采用优雅的垂直拉伸动画。
- **列表排序**：点击顶部的排序按钮（正序/倒序）时，年份、月份和文章都会通过 FLIP 动画平滑地交换位置。

## 配置

归档页面通常不需要额外配置，它会自动读取你的文章数据并按时间生成。

如果你需要自定义归档页面的路由或标题，可以在 `valaxy.config.ts` 或页面 frontmatter 中进行设置。
